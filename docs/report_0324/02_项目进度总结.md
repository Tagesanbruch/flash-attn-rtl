## 2. 项目进度总结

本项目的推进大致经历了五个阶段。第一阶段是功能基线搭建，主要完成 Q8.8 定点算术原语、online softmax 基本链路、控制寄存器映射和 DMA 基础接口，使得顶层能够完成从配置、启动到完成的完整状态流转。第二阶段是精度与周期的系统审计，通过 Python 参考模型、C++ CModel 和 Verilator 对照路径，明确区分“算法级浮点近似正确”与“RTL 同构定点正确”这两个口径，并逐步将主线实现收敛到通过精度门限的版本。第三阶段是架构级优化，重点包括控制空拍压缩、K/V 双缓冲重叠、row2 并行组织与性能计数器读回，使主线周期先降到十几万级。第四阶段是面向 55nm 工艺的模块级 PPA 优化，通过在 `experiments/` 目录下构造对照实验，分析倒数、online softmax、QK 点积与归一化模块的结构性时序瓶颈。第五阶段则是把 `exp_h + ctx/exp_d + exp_d` 这组高频 leaf 真正以 tag 化、批流式和多上下文交错的方式吸收到 `fa_attention_core` 中，使当前主线周期进一步收敛到 `85928`。

从阶段成果看，当前主线已经完成以下几项关键闭环。其一，设计层面已经实现 `fa_attention_ip_top`、`fa_attention_core`、`fa_dma_reader`、`fa_dma_writer`、`fa_axi_lite_regs` 等核心模块，并具备完整的数据搬运与控制路径。其二，验证层面已经建立包含单模块回归、顶层寄存器回归、全参数 attention core 回归、Verilator C++ 直跑和 CModel 对照在内的多口径体系。其三，指标层面已经给出端到端周期、误差、带宽和模块级 STA 的系统数据，并以当前 `main` 的 `85928 cycles` 与 `MaxAE=0.006583` 形成新的统一主线口径。其四，优化层面已经证明：问题确实可以从“leaf 频率不足”转化为“system-level overlap 闭环”，并进一步被当前主线解决；当前剩余的重点已从“周期达标”转向“bonus 扩展能力与更完整 PPA 收敛”。

## 2.2 各方向阶段结论

### 2.2.1 baseline / main

- 口径稳定：`cycles=85928`。
- 误差稳定：`MAE=0.002499`, `MaxAE=0.006583`。
- 状态：作为 strict-problem 基线继续有效。

### 2.2.2 Bonus #3/#4/#5（`exp/padding-mask-s512`）

- `valid_len` 已接入 top/core，并完成 `valid_len=192` 回归。
- `S=512` 已完成 top/IP 级闭环（不再仅 core 级）。
- `Q6.10/Q4.12` 已完成外部格式桥接与回归。
- 代表结果：
  - `S=512`: `cycles=307024`, `MAE=0.002235`, `MaxAE=0.006685`
  - `valid_len=192`: `cycles=73880`, `MAE=0.001868`, `MaxAE=0.006583`
  - `Q6.10/Q4.12`: `MAE=0.004218`, `MaxAE=0.009086`

### 2.2.3 Bonus #2（`exp/bonus2-mha`）

- 实现策略：单 core 顺序执行 multi-head。
- 周期与计数严格线性扩展：
  - `head=1`: `85928`
  - `head=2`: `171856`
  - `head=4`: `343712`
  - `head=8`: `687424`
- 含义：top 级 head 调度几乎无额外开销，瓶颈仍在单 head core。

### 2.2.4 Bonus #9（`exp/bonus9-task-queue`）

- 从 P1 shadow-next 过渡到 P2 true FIFO。
- 默认 `FIFO_DEPTH=4`，参数化支持 `1..15`，已回归 `DEPTH=8`。
- 增加 descriptor 对齐校验、overflow/underflow/desc_error sticky、flush 语义。
- 顶层回归通过：默认和 `FIFO_DEPTH=8` 均 `PASS`。

### 2.2.5 Bonus #1（`exp/bonus1-bf16`）

- BF16 core 周期从 `8,573,025` 迭代到 `2,150,497`（dot/softmax 并行+重叠）。
- BF16/FP16 统一模式完成：单 RTL、运行时 `precision_mode` 切换。
- FP16/BF16 核心测试通过，周期口径一致。
- 但相对 Q8.8 baseline 仍有数量级吞吐差距，尚未进入主线替代阶段。

### 2.2.6 Bonus #7（`exp/int8-fp8-bootstrap`）

- 已完成 INT8/FP8 基础组件、最小 core、full core、DMA 版原型。
- RTL 与同构 fixed/cmodel 对齐可做到 `max_err=0`。
- 但相对 FP32 误差仍高（常见 `MAE≈3.x`, `MaxAE≈8`），说明数值链路尚不满足 baseline 门限级要求。

### 2.2.7 推理接入（`exp/fpga` -> `exp/mode15-k-smooth`）

- DPI backend、C API、task submit 骨架已建。
- cmodel mode14 修复后可稳定输出可读文本并通过 role prompt 对照。
- mode15/mode16/mode17（纯 fixed 路线）在 chat 上有明显进步，但 role 结构仍不稳。
