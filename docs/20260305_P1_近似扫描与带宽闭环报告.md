## 3. 产物

### 3.1 近似扫描汇总

- `docs/data/20260305_p1_approx_scan_summary.csv`

关键观察：

- `rtl_exact` / `rtl_real_exp` 在 cmodel 历史口径下仍 FAIL（这是旧算术路径参考，不代表当前 RTL 已达标状态）。
- `fixed_hiacc_real_exp_qout`：
  - small-int causal（neg/hard）均 PASS；
  - gaussian causal hard PASS；
  - gaussian causal neg 出现 `MaxAE` 超限（FAIL）。

结论：高动态输入下需要更稳健的掩码/归一化组合，不能只看平均 MAE。

### 3.2 带宽闭环汇总

- `docs/data/20260305_p1_bandwidth_summary.csv`

从当前 RTL 统计（`total_cycles=145,584`）得到：

- `rd_bytes = 557,040`
- `wr_bytes = 32,768`
- `total_bytes = 589,808`
- `avg_bytes_per_cycle = 4.051324`
- `bus_peak_bytes_per_cycle = 16`
- `bus_utilization = 25.3208%`

结论：当前版本 compute 已明显压缩，后续若继续追吞吐，应优先优化访存并行度与有效带宽利用。

### 3.3 同步对比数据

- `docs/data/20260304_rtl_cmodel_compute_compare.csv`
- `docs/report/20260304_rtl_cmodel_compute_compare.png`

当前对比（模型 `fixed_flow_l32_norm8_row2`）：

- RTL `Compute+Norm_Total = 133,256`
- CModel `Compute+Norm_Total = 100,608`
- 差值 `+32,648`

结论：相比早期 98k 级差距已显著收敛，后续可针对主状态外开销继续压缩。
