# 6 综合时序与工程化（20260305）

## 6.1 工程入口

根 `Makefile` 提供统一入口：

- lint：`make lint`
- 仿真：`make test` / `make regress`
- 周期画像：`make rtl-latency-profile`
- cmodel：`make cmodel-compute-adv`
- 对比：`make rtl-cmodel-compare`
- STA：`make sta-list` / `make sta ...`

## 6.2 STA 组织方式

- 模块清单：`cfg/sta_modules.mk`
- 约束：`syn/sdc/default_clocked.sdc`、`syn/sdc/default_comb.sdc`
- 脚本：`syn/scripts/sta_no_power.tcl`
- 输出：`syn/<module>_<date>/`

## 6.3 当前工程化状态

已形成“RTL 修改 -> 一键回归 -> 数据导出 -> 图表更新”的闭环，关键数据统一落在 `docs/data/`，图表统一落在 `docs/report/`，便于版本比较和后续开发交接。
