# 2 系统架构与模块划分（20260305）

## 2.1 顶层架构

当前实现采用“主控 + 计算核心 + DMA 接口”三段式：

1. AXI-Lite 配置寄存器（控制启动、地址、stride、scale、mask 参数）
2. attention core（tile-loop + online softmax + normalize）
3. DMA reader/writer（Q/K/V 读，O 写）

对应目录：

- `rtl/top/`
- `rtl/core/`
- `rtl/bus/`
- `rtl/softmax/`
- `rtl/common/`

## 2.2 当前关键模块职责

- `fa_attention_core.sv`
  - 主状态机：`S_LOAD_Q -> S_INIT_CONTEXT -> S_LOAD_K -> S_LOAD_V -> S_COMPUTE -> S_NORMALIZE -> S_WRITE_O`
  - 子状态机：`C_DP_RUN -> C_SCORE_DONE -> C_SOFTMAX_PREP`
  - 在线状态：`row_m/row_l/row_acc`
  - P0 后支持 K/V ping-pong 预取

- `fa_exp_pwl_8seg_q1_15.sv`
  - softmax 路径指数近似

- `fa_recip_nr_q16_16.sv`
  - normalize 分母倒数近似

## 2.3 数据流组织（当前版）

1. 按 Q tile 装载 `TQ x D`
2. 初始化行上下文 `m/l/acc`
3. 对每个 K/V tile：
   - 当前 bank compute
   - 另一 bank 预取下一 tile（P0）
4. 全 K/V 处理后做 normalize
5. 写回 O tile

该组织满足“不存 SxS 中间矩阵”的赛题要求。
