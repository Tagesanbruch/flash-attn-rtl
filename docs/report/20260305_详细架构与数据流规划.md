# 20260305 详细架构与数据流规划

## A. 主状态机

当前 `fa_attention_core` 主状态序列：

`S_LOAD_Q -> S_INIT_CONTEXT -> S_LOAD_K -> S_LOAD_V -> S_COMPUTE -> S_NORMALIZE -> S_WRITE_O -> S_NEXT_Q`

其中：

- `S_COMPUTE` 内部同时承载 compute 子 FSM 与预取 FSM。

## B. compute 子 FSM

当前压缩后的子状态：

`C_DP_RUN -> C_SCORE_DONE -> C_SOFTMAX_PREP`

含义：

- `C_DP_RUN`：row2 并行点积
- `C_SCORE_DONE`：缩放 + causal mask
- `C_SOFTMAX_PREP`：在线 softmax 更新 + PV 累积

## C. K/V 双缓冲预取

新增 bank：

- active bank：参与当前计算
- prefetch bank：加载下一 tile

预取状态机：

`PF_CMD_K -> PF_DATA_K -> PF_CMD_V -> PF_DATA_V -> PF_DONE`

在 `PF_DONE` 且当前 compute 完成时，bank 翻转并进入下一 tile 计算。

## D. 数值稳定路径

- normalize 保留分母 0 保护
