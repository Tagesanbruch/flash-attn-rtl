# 4 RTL实现与接口寄存器（20260305）

## 4.1 顶层与核心文件

- 顶层：`rtl/top/fa_attention_ip_top.sv`
- 核心：`rtl/core/fa_attention_core.sv`
- 软算子：`rtl/softmax/*`
- DMA/AXI-Lite：`rtl/bus/*`

## 4.2 P0 对 RTL 的主要修改

### 4.2.1 控制路径压缩

- 删除中间状态（`C_DP_INIT/C_NEXT_KJ/C_NEXT_QI`）并内联
- 主状态去掉单独 `S_NEXT_K`

### 4.2.2 K/V 双缓冲重叠

- K/V 从单 bank 改为 `buf0/buf1`
- compute 阶段引入预取状态机：`PF_CMD_K -> PF_DATA_K -> PF_CMD_V -> PF_DATA_V`

### 4.2.3 在线软最大稳定增强

- `l_new_safe` 分母保护

## 4.3 与赛题寄存器模型的对齐

项目保留了对 `start/done/busy`、地址基址、stride、scale、causal 等核心控制语义支持，且已通过顶层寄存器测试路径（见第5章）。
