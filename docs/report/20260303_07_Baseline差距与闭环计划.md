# 7 Baseline差距与闭环计划

## 7.1 现状对照（按赛题必选项）

### 7.1.1 已满足/部分满足项

- online softmax 子路径：已具备 RTL 与测试证据；
- 禁止显式 `S×S` 存储：当前结构层面满足；
- AXI4-Lite 寄存器：已实现并验证核心语义；
- 算法模型误差：在 `S=256,d=64,causal` 下显著优于门限。

### 7.1.2 关键缺口项

- AXI4 Master + DMA 数据搬运：未完成；
- K/V tiling 数据面：未完成；
- RTL 端到端 `S=256,d=64` 验证：未完成；
- CYCLES 与 RD/WR bytes 真实统计：未完成；
- top 级 PPA（面积/时序/功耗）：未完成。

这些缺口并非“细节优化”，而是决定是否通过 Baseline 验收的主干项。

## 7.2 闭环目标定义（必须满足）

Baseline 最终闭环定义为以下 5 条同时成立：

1. 功能闭环：RTL 端到端输出 O 正确；
2. 约束闭环：online + tiling + 无 `S×S` 存储；
3. 接口闭环：AXI-Lite + AXI Master DMA 可用；
4. 指标闭环：误差、cycles、带宽数据齐全；
5. 实现闭环：top 级 PPA 报告可复核。

## 7.3 分阶段执行计划

## 阶段A：DMA 最小可用（预计 3~5 天）

### 目标

把外存读写链路打通，使 Q/K/V/O 可以通过 AXI 主口流动。

### 交付

- top 增加完整 `m_axi_*` 端口；
- 简化 DMA FSM（先不追求高并发）；
- `RRESP/BRESP` 错误上报到 `STATUS.ERROR`；
- 内存模型 cocotb 用例通过。

### 验收标准

- 单次运行无死锁；
- O 区域能写回非零有效数据；
- 错误注入能触发 ERROR 位。

## 阶段B：tiling 与 online 状态贯通（预计 4~6 天）

### 目标

实现 K/V 分块处理与跨 tile 的 `m/l/acc` 持续更新。

### 交付

- tile buffer（至少 K/V）；
- tile-loop 控制器；
- 行级状态寄存器 bank；
- causal 条件在 tile 级可正确生效。

### 验收标准

- 小规模 case（如 S=32）与 Python golden 对齐；
- 不出现 score/p 全矩阵存储结构；
- tile 边界切换无状态丢失。

## 阶段C：S256D64 端到端正确性（预计 2~4 天）

### 目标

在赛题固定规模上完成 RTL 端到端误差验收。

### 交付

- 随机 Q/K/V 激励生成与内存装载；
- 运行完成后 O 读回并与 golden 对比；
- 自动输出 MAE/MaxAE 报告。

### 验收标准

- MAE <= 0.03；
- MaxAE <= 0.10；
- causal corner（如 i=0）行为正确。

## 阶段D：性能与带宽统计（预计 2~3 天）

### 目标

生成可用于答辩/评审的性能证据。

### 交付

- CYCLES 真实统计（寄存器或日志）；
- RD_BYTES/WR_BYTES 统计；
- 与 tile 大小相关的对比实验（至少 2 组）。

### 验收标准

- 指标采集可重复；
- 统计口径清晰；
- 能解释瓶颈来源（访存或计算）。

## 阶段E：top 级综合与报告收敛（预计 3~5 天）

### 目标

形成可提交的 PPA 与实现章节。

### 交付

- top 级综合与 STA 报告；
- 功耗估计（条件允许下）；
- 最终报告图表与结论。

### 验收标准

- 报告数据可追溯到脚本与原始输出；
- 与功能结果版本一致；
- 不存在“功能通过但实现数据缺失”的断层。

## 7.4 风险清单与预案

### 风险1：DMA 握手复杂导致调试周期拉长
- 预案：先实现单 outstanding，验证稳定后再扩展并发。

### 风险2：tile 边界数值不稳定
- 预案：把 tile 前后状态导出到日志，先对单行逐步比对。

### 风险3：时序压力集中在 exp/recip 与乘累加链
- 预案：提前规划流水切分点，不在功能未稳时做大规模重构。

### 风险4：误差达标但性能不达标
- 预案：先保证正确，再通过 tile 大小、访存并行和流水调整优化 cycles。

## 7.5 本章小结

当前项目距离 Baseline 完整达标的路径是清晰且可执行的。核心不是“再写更多模块”，而是按阶段把 DMA、tiling、端到端验证、性能统计和 top 级实现报告串成闭环。
