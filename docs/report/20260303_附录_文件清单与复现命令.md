## A.2 常用复现命令

以下命令在仓库根目录执行：

1. 代码静态检查

```bash
make lint
```

2. cocotb 回归

```bash
make regress
```

3. 顶层寄存器测试

```bash
make test MODULE=fa_attention_ip_top
```

4. 严格 online 算法审计

```bash
make audit-algo
```

5. 与 torch 对比（默认）

```bash
make compare-torch
```

6. 指定 S256D64 多 seed 对比

```bash
python dv/python/torch_compare.py \
  --s 256 --d 64 --causal \
  --n-seeds 5 --seed 20260303 \
  --csv-out report/data/20260303_torch_compare_s256d64.csv
```

7. 查看可跑 STA 模块

```bash
make sta-list
```

8. 跑单模块 STA（示例）

```bash
make sta-module STA_MODULE=fa_core_controller STA_DATE=20260303
make sta-module STA_MODULE=fa_mul_sat_q8_8 STA_DATE=20260303
```

## A.3 当前结果解释口径

- `algorithm_audit.csv`：验证 online 递推与 direct softmax 的数学一致性；
- `torch_compare_s256d64.csv`：验证模型级误差门限；
- 单模块 STA 报告：仅代表模块级趋势，不代表 top 级最终结论。
