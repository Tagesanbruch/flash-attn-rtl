# 3 核心算法与定点设计（20260305）

## 3.1 算法主线

实现目标是 SDPA 等价（baseline）：

$$
O = softmax(QK^T / \sqrt{d} + M) V
$$

当前 RTL 路线：

- 在线 softmax（行级维护 `m/l`）
- tile 化处理 K/V
- 不存完整 `score` 与 `P`

## 3.2 定点路径

- 输入：Q8.8
- 点积累加：更宽累加寄存器（当前 `row_acc` 为 64 位）
- exp：PWL 近似
- recip：NR 近似
- 输出：Q8.8 饱和

## 3.3 数值稳定策略

P0 新增稳定守护：

- `l_new_safe = (l_new == 0) ? 1 : l_new`
- normalize 分母为 0 时走安全分支

结果：性能优化后精度不退化（见 `docs/data/20260304_rtl_summary.csv`）。
